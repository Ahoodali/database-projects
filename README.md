# 🗄️ Database Project

## 📌Project Overview

This project was created as part of my Database learning journey on Satr Platform 🎓.

The same database project was implemented using three different database technologies:

* 🐬 MySQL
* 🍃 MongoDB
* 🔥 Firebase Firestore

The goal was to practice creating, storing, querying, and managing the same type of data using different database systems 💻.

## 💡 Project Idea

The project is a database for managing graduates, companies, majors, company branches, and job applications 📊.

It includes information such as:

* 🎓 Graduates and their graduation years
* 📚 Academic majors
* 🏢 Companies and their branches
* 📝 Job applications
* 📌 Application status such as Accepted, Rejected, and Pending
* 💼 Employment information

## 🛠️ Technologies Used

### 1. 🐬 MySQL

MySQL was used to create a relational database containing tables for the project data 🗃️.

I practiced:

* 🏗️ Creating databases and tables
* 🔑 Primary and foreign keys
* 🔗 Relationships between tables
* ➕ INSERT, ✏️ UPDATE, and 🗑️ DELETE
* 🔍 SELECT queries
* 🔄 JOIN
* 🎯 WHERE
* 📊 GROUP BY
* ↕️ ORDER BY
* 🧮 Aggregate functions

The MySQL folder contains the database dump and SQL queries used in the project 📁.

### 2. 🍃 MongoDB Atlas & Compass

The same project data was implemented using MongoDB Atlas as a NoSQL database.

I also used MongoDB Compass to connect to and manage the MongoDB database and its collections.

I practiced:

* 📦 Collections
* 📄 Documents
* 🧾 JSON data
* 🔎 Queries
* 📈 Aggregation
* 🔗 Working with related data in a NoSQL structure

The MongoDB folder contains the exported JSON collections.

### 3. 🔥 Firebase Firestore

The same project data was also implemented using Firebase Firestore.

I exported the collections from MongoDB Atlas as JSON files, then used Firefoo to import the JSON data into Firebase Firestore.

This allowed me to use the same project data in both MongoDB and Firebase Firestore and understand how the same data can be managed in different NoSQL database systems.
