# 🗄️ Database Project

## 📌Project Overview

This project was created as part of my Database learning journey on Satr Platform 🎓.

The same database project was implemented using three different database technologies:

* 🐬 MySQL
* 🍃 MongoDB
* 🔥 Firebase Firestore

The goal was to practice creating, storing, querying, and managing the same type of data using different database systems 💻.

## 💡 Project Idea

The project is a database for managing graduates, companies, majors, company branches, and job applications 📊.

It includes information such as:

* 🎓 Graduates and their graduation years
* 📚 Academic majors
* 🏢 Companies and their branches
* 📝 Job applications
* 📌 Application status such as Accepted, Rejected, and Pending
* 💼 Employment information

## 🛠️ Technologies Used

### 1. 🐬 MySQL

MySQL was used to create a relational database containing tables for the project data 🗃️.

I practiced:

* 🏗️ Creating databases and tables
* 🔑 Primary and foreign keys
* 🔗 Relationships between tables
* ➕ INSERT, ✏️ UPDATE, and 🗑️ DELETE
* 🔍 SELECT queries
* 🔄 JOIN
* 🎯 WHERE
* 📊 GROUP BY
* ↕️ ORDER BY
* 🧮 Aggregate functions

The MySQL folder contains the database dump and SQL queries used in the project 📁.

### 2. 🍃 MongoDB Atlas

The same project data was implemented using MongoDB as a NoSQL database 🌐.

I practiced:

* 📦 Collections
* 📄 Documents
* 🧾 JSON data
* 🔎 Queries
* 📈 Aggregation
* 🔗 Working with related data in a NoSQL structure

The MongoDB folder contains exported JSON collections 📁.


### 3. 🔥 Firebase Firestore

The same project data was implemented using Firebase Firestore.

I exported the collections from MongoDB Atlas as JSON files and then imported these JSON files into Firebase Firestore using Firefoo.

This allowed me to use the same project data in Firebase and understand how NoSQL data can be managed using Firestore.

## 🎯 What I Learned

Through this project, I practiced working with different database technologies and understood how the same data and relationships can be represented in different database systems 🧠.

This project helped me compare relational databases such as MySQL with NoSQL databases such as MongoDB and Firebase Firestore ⚖️.

* ✅ Implemented the same project using three database technologies
* ✅ Practiced relational database concepts
* ✅ Practiced NoSQL database concepts
* ✅ Worked with SQL queries and JSON documents
* ✅ Compared different ways of storing and managing data
* ✅ Improved my understanding of database design and data relationships
